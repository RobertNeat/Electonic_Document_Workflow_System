# Kontrakt: document_api ↔ frontend (moduł Dokumenty i szablony)

Moduł Dokumenty (`apps/document_web/src/app/features/dokumenty/`) jest podłączony do
rzeczywistego `document_api` dla listy/szczegółów dokumentu, wersji, listy/historii/uploadu
szablonów Jasper oraz podpisywania. Brak pozostałych nieobsłużonych endpointów w tym module.
